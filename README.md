## 📄 Descrição do entregável

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido para apresentar minha trajetória como desenvolvedor, meus principais projetos, tecnologias e formas de contato.

## 💻 Sobre o projeto

O **Portfólio - Davi Ferreira** é um projeto desenvolvido para funcionar como minha principal vitrine profissional na área de desenvolvimento web.

O objetivo é apresentar de forma clara e moderna:

- Minha apresentação profissional;
- Minhas principais habilidades e tecnologias;
- Projetos desenvolvidos ao longo da minha jornada;
- Informações sobre minha experiência e aprendizado;
- Links para minhas redes profissionais;
- Formas de entrar em contato comigo.

Além de cumprir seu objetivo profissional, o projeto também demonstra na prática meus conhecimentos em **React, JavaScript, componentização, organização de código, responsividade e desenvolvimento de interfaces modernas**.

## 🚀 Como executar o projeto

### Pré-requisitos

Antes de começar, você precisa ter instalado em sua máquina:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)
- Um editor de código, como [Visual Studio Code](https://code.visualstudio.com/)

### Executando o projeto

```bash
# Clone o repositório
git clone https://github.com/Dferreiraz/Portfolio.git

# Acesse a pasta do projeto
cd Portfolio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Depois, acesse a URL exibida pelo Vite no terminal, normalmente:

```text
http://localhost:5173
```

### Outros comandos disponíveis

```bash
# Gerar a versão de produção
npm run build

# Visualizar a build de produção localmente
npm run preview

# Executar o ESLint
npm run lint
```
